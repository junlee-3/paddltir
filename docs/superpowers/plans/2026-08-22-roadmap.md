## Shared contracts (all plans must honour)
- **Lexicographic priority** (lower is better at every position):
  `(−seated, −totalPower, weightDelta, sideMismatches, seatMismatches, powerDelta, |trimMoment|, moves)`
  — `totalPower` = Σ erg metres of seated paddlers (selection quality; added so the
  optimiser never benches a strong paddler to shave a few hundred grams of imbalance).
- **Arms:** bench `b` → `b − (n+1)/2`; drummer `−(n+1)/2`; sweep `+(n+1)/2`.
- **Sections:** stroke = bench 1; sprint = round(0.3·n) last benches; pace =
  round(0.2·n) benches after stroke; engine = the rest. (n=10 → 1 / 2–3 / 4–7 / 8–10;
  n=5 → 1 / 2 / 3 / 4–5.)
- **Eligibility:** roles `paddler` and `drummer` may be benched; `sweep` never.
  The heat's drummer/sweep are never benched; their weights feed the trim term.
- **Gender rule** = `{minWomen?, maxWomen?, minMen?, maxMen?}` counted over benched
  paddlers only. Hard when feasible; if infeasible both algorithms relax it fully and
  report `ruleSatisfied=false`.
- **Fixture JSON schema:** defined in `fixtures/README.md` (Plan 1, Task 1). Python
  (Plan 3) reads the same files and the same camelCase keys.
- **Moves** = number of `current` seat assignments that are not preserved.
